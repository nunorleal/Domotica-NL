# Pavimento com repetição contínua

Ferramenta integrada: ImageGen. Imagem original gerada: paralelos-seamless-v2.png. A aplicação usa paralelos-seamless-v2.svg, que integra a imagem num padrão nativo com quatro reflexões para fazer coincidir os pixels das bordas em ambas as direções. Tamanho de fundo: 400 × 400 px (cada quadrante tem 200 × 200 px).

## Prompt

Use case: precise-object-edit. Input image is the style/material reference for a repeating pavement background. Produce a SQUARE 1024x1024 SEAMLESS TILEABLE texture of these same dark anthracite Portuguese granite street cobblestones (paralelos), orthographic overhead. Critical: left and right edges wrap continuously with matching stone shapes, mortar rows, colors and grain; top and bottom edges likewise match perfectly. No seam lines, no cut-off stone mismatches, no illumination gradient, no vignette, no dark border, no frame. Use evenly spaced small irregular rectangular granite blocks in subtly staggered horizontal rows, around 12 columns by 12 rows, uniform low-contrast charcoal grey, same photographic microtexture and narrow mortar joints as reference. Seamless material/albedo texture, edge-to-edge. All illumination completely even and neutral. No objects, no text, no perspective. Designed for CSS background-repeat at 240x240px, so no conspicuous landmarks or repeating patches.
